# 주하의 말랑말랑 한글마을

별도 패키지 설치 없이 Node.js 20.11 이상에서 실행하는 한글 학습 웹앱입니다.

```sh
git clone https://github.com/toyoo1004/juha-learning.git
cd juha-learning
npm start
```

기본 포트는 3000이며 `PORT=3001 npm start`로 변경할 수 있습니다. 테스트는 `npm test`입니다.

- 소리 빵집: 자모 클릭/드래그, 유니코드 한글 합성, 기본 36개·심화 38개 미션. 기본은 자음과 모음을 놓으면 자동으로 굽고, 심화는 받침까지 고른 뒤 **글자 빵 굽기**를 누릅니다. 받침을 고르기 전에 글자가 넘어가지 않도록 한 방식입니다.
- 단어 놀이터: 기본 36개·심화 40개 단어, 같은 첫 글자 오답, 3/4장 보기, 카테고리 필터, 두 번 오답 후 도움, 정답 그림, 노래방 문장, 스스로 읽기, 별 스탬프.
- 음성: 브라우저 Web Speech API의 한국어 음성을 사용합니다. 기기에 따라 음성 설치가 필요할 수 있으며 처음 재생에는 사용자 클릭이 필요합니다. 녹음 음원은 포함하지 않았습니다.
- 자막: 녹음 타이밍 → speech boundary → 추정 시간 순으로 사용합니다. 추정 시간은 실제 발화와 차이가 있으므로 부모 설정에서 조절할 수 있습니다. 설정과 별은 이 기기의 localStorage에 저장됩니다.

## 선택 녹음 음원

`audio/<audioKey>.mp3`와 같은 이름의 `.json`을 함께 추가하면 브라우저 음성보다 우선합니다. `data.js`에 모든 단어·문장의 키가 있습니다. JSON은 초 단위 시간과 UTF-16 글자 인덱스를 담는 배열입니다.

```json
[{"charIndex":0,"charEnd":1,"start":0.0,"end":0.4},{"charIndex":1,"charEnd":2,"start":0.4,"end":0.8}]
```

문장은 글자별 항목을 권장합니다. 음원/JSON이 없거나 재생이 실패하면 TTS로 전환합니다. 외부 API 키와 서비스는 필요하지 않습니다.

## 검증

`npm test`는 11,172개 한글 조합 왕복, 단어 수·난이도·데이터 필드, 같은 첫 글자의 오답 포함과 보기 중복 방지, 셔플의 원본 보존을 검증합니다. Chromium에서 기본 미션 완성, 받침 잠금/해제, 부모 설정 저장, 정답 그림 공개, 따라 읽기와 별 지급, 다음 문제, 모바일 가로 넘침을 추가 확인했습니다. 자동화에서는 음성 이벤트를 모킹하였으며 실제 한국어 음질은 사용하는 기기에서 확인해 주세요.

브라우저 검증 스크립트는 `tests/browser-smoke.py`와 `tests/speech-smoke.py`입니다. 서버 실행 후 Playwright Python과 `/usr/bin/chromium`이 있는 환경에서 각각 실행할 수 있습니다. 음성 이벤트를 모킹하므로 실제 스피커 출력 검증은 포함하지 않습니다.
